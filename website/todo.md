# Sayyoralar xaritasi yangilanishi

- [x] Sayyora taxtasini 4 qatorli kompozitsiyaga qayta tuzish: 1- va 4-qator qisqa, 2- va 3-qator uzun.
- [x] Quyoshni 4 qatorni qamrab olgan umumiy konteynerning haqiqiy markaziga joylashtirish.
- [x] “MVP’da faol”, “Qulflangan” va “Tez kunda” holatlarini barcha sayyora kartalaridan olib tashlash.
- [x] Sakkiz sayyora uchun qisqa, mazmunli ko‘nikma tavsiflarini ko‘rsatish.
- [x] Header va footer’dan generatsiya qilingan belgini olib tashlab, faqat foydalanuvchi yuborgan Kichik Alloma logotipini qoldirish.
- [x] Sayyora qatorlarining alohida rangli fonlari va chegaralarini olib tashlash.
- [x] Birinchi hamda to‘rtinchi qisqa qatorni ham umumiy konteyner markaziga tekislash.
- [x] Markaziy Quyosh uchun foydalanuvchi yuborgan `Document.webp` tasviridan foydalanish.
- [x] Desktop va mobil ko‘rinishda yangi kompozitsiyani tekshirish.
